# Game_Bogolyubova

Flowalive — платформер на JavaScript

ЗАПУСК
Открыть index.html в браузере. Всё работает без сервера и без установки.

УПРАВЛЕНИЕ
A / D или стрелки влево/вправо — движение
W / стрелка вверх / Space — прыжок
E — щит
Q — огненная сфера
Esc — пауза / выход в меню
F2 — показать/скрыть диагностику картинок

ПРАВИЛА
Собрать свитки, дойти до короны, не касаться ядовитых цветов.
Очки: +10 за свиток, +100 за финиш. Рекорд сохраняется в localStorage.

НЕЙРОСЕТЬ
Игра создана с помощью DeepSeek — генерация кода, отладка, рефакторинг.

ПРИМЕРЫ ПРОМПТОВ
1. Сделай платформер на JS + Canvas: коллизии, гравитация, прыжок.
2. Добавь три уровня, меню выбора уровня, паузу, рестарт и рекорд в localStorage.
3. Добавь счёт в очках и авто-паузу при уходе со вкладки (visibilitychange).
4. Разбей игру на файлы: config, input, collision, Player, Game, Renderer, main. Без ES-модулей.

РЕСУРСЫ
Графика: все изображения (img/*.png) — собственные, отрисованы автором.
Звук: отсутствует.
